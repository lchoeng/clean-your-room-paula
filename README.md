# Clean Your Room! Friends Edition

A copy of Clean Your Room! with friends as the characters. Daddy chases Mommy, Olivia or Maya through the house because he wants them to clean their rooms!

**Play:** open `index.html` in a browser (works on iPhone — turn it sideways).

## Controls
- **Phone:** tap the right side to JUMP, hold the left side to DUCK, pause button top-right
- **Keyboard:** Space = Jump, ↓ = Duck, Esc = Pause, 1–3 = pick a character

## Features
- 3 playable characters + Daddy the chaser, from the user's own sprite sheet: stance, running, jump-kick and crouch poses
- Daddy's spinning towel whip — jump to dodge it!
- 5 levels: Messy Bedroom, Living Room, Kitchen, Backyard, Toy Store
- Power-ups, music, sound effects, Daddy's catchphrases, saved best scores

Single self-contained HTML file — no build step. Character art in `art/` (standing poses, `runA_*` run, `runB_*` jump, `duck_*` crouch).
